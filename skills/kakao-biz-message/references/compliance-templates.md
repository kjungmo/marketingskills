# 친구톡·광고성 메시지 규제 문구 (정보통신망법)

> `kakao-biz-message` skill의 참고 자료입니다. **현재 기준 확인 필요** — 정보통신망법·시행령은 개정될 수 있으므로 실제 발송 전 최신 법령과 카카오 정책을 재검증하고, 필요 시 법률 검토를 받습니다. 본 문서는 법률 자문이 아닙니다.

## 광고성 메시지 발송 체크리스트

광고성 정보(친구톡 등)를 보낼 때 확인합니다.

- [ ] **사전 수신 동의(옵트인)** 확보 — 채널 친구 추가 시 광고 수신 동의 범위를 명확히 고지
- [ ] 메시지 시작부에 **(광고)** 표기
- [ ] 전송자(브랜드/업체) 명칭 명시
- [ ] **무료 수신거부** 수단·방법 안내
- [ ] **야간(21시~익일 08시)** 발송 시 **별도 사전 동의** 확보
- [ ] 개인정보(전화번호 등) 수집·이용은 개인정보보호법상 동의·고지 전제

## 문구 템플릿

### (광고) 표기
메시지 **맨 앞**에 표기합니다.
```
(광고) [브랜드명] …본문…
```

### 무료 수신거부 안내
친구톡은 채널 차단으로 수신거부가 가능합니다. 본문 하단에 명시합니다.
```
무료수신거부: 카카오톡 채널 차단
```
(문자 병행 시 예: `무료수신거부 080-XXX-XXXX`)

### 옵트인(채널 추가 시) 동의 고지 예시
```
채널을 추가하시면 [브랜드]의 혜택·이벤트 등 광고성 정보를 카카오톡으로 받아보실 수 있습니다.
수신은 언제든 채널 차단으로 중단할 수 있습니다.
```

### 야간 전송 별도 동의 예시
```
21시~익일 08시 야간 시간대 광고성 메시지 수신에 동의합니다. (선택)
```

## 알림톡 vs 친구톡 빠른 판별

| 내용 | 분류 | (광고) 표기 | 옵트인 |
|---|---|---|---|
| 주문·배송·예약·인증 등 거래 사실 안내 | 알림톡(정보성) | 불필요 | 불필요 |
| 할인·쿠폰·이벤트·재구매 유도 등 홍보 | 친구톡(광고성) | **필요** | **필요** |

> 알림톡에 할인·홍보 문구를 섞으면 정보성 요건을 벗어나 위반 소지가 생깁니다. 광고성은 반드시 친구톡으로 분리합니다. 카피 표현 자체의 과장·미입증 점검은 `kr-ad-compliance` 를 사용합니다.
