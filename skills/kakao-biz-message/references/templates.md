# 카카오 알림톡·친구톡 템플릿 갤러리

> `kakao-biz-message` skill의 참고 자료입니다. 카카오 비즈메시지 정책·심사 기준은 수시 변동하므로 등록 전 카카오 공식 가이드를 재확인합니다. 변수는 `#{변수명}` 형식으로 치환됩니다.

## 알림톡 (정보성 — 거래·안내)

광고성 문구를 넣지 않습니다. 거래 발생 사실의 안내에 한정합니다.

### 주문 완료
```
[#{쇼핑몰명}] 주문이 완료되었습니다.

· 주문번호: #{주문번호}
· 상품: #{상품명}
· 결제금액: #{결제금액}원

빠르게 준비해 발송해 드리겠습니다.
```
버튼: `주문 상세보기`(웹링크)

### 배송 출발
```
[#{쇼핑몰명}] 상품이 발송되었습니다.

· 운송장번호: #{운송장번호}
· 택배사: #{택배사}

배송 조회 버튼에서 실시간 위치를 확인하세요.
```
버튼: `배송 조회`(웹링크)

### 예약 확인
```
[#{업체명}] 예약이 확정되었습니다.

· 일시: #{예약일시}
· 인원: #{인원}
· 위치: #{매장명}

변경/취소는 아래 버튼을 이용해 주세요.
```
버튼: `예약 변경`, `오시는 길`

### 인증번호
```
[#{서비스명}] 인증번호는 [#{인증번호}] 입니다.
타인에게 노출하지 마세요. (유효시간 3분)
```

## 친구톡 (광고성 — 채널 친구 대상)

채널 친구(옵트인)만 수신합니다. **(광고)** 표기와 수신거부 안내가 필요합니다(상세는 `compliance-templates.md`).

### 프로모션
```
(광고) [#{브랜드}] #{고객명}님만을 위한 단독 혜택 🎁

이번 주말 전 상품 20% 쿠폰 도착!
지금 받아서 바로 사용해 보세요.

무료수신거부: 채널 차단
```
버튼: `쿠폰 받기`(웹/앱링크)

### 재구매 유도
```
(광고) [#{브랜드}] 그때 그 #{상품명}, 떨어질 때 되지 않으셨나요?

재구매 고객 전용 15% 혜택을 준비했어요.

무료수신거부: 채널 차단
```
버튼: `다시 구매하기`

### 휴면 리마인드
```
(광고) [#{브랜드}] #{고객명}님, 오랜만이에요 👋

돌아오신 분들께 드리는 컴백 쿠폰이 있어요.

무료수신거부: 채널 차단
```
버튼: `혜택 확인`

## 작성 팁

- **한 메시지 = 한 목적/한 CTA.** 버튼은 행동 경로를 단축합니다.
- **변수 과다 주의**: 알림톡 심사에서 변수만으로 구성된 본문, 광고성 변수는 반려될 수 있습니다.
- **알림톡에 혜택·할인 문구 금지**: 정보성 요건을 벗어나면 정보통신망법 위반 소지 → 친구톡으로 분리.
- 모바일 가독성 우선, 핵심부터.
