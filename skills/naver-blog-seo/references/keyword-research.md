# 네이버 키워드 리서치 & 군집 설계

> `naver-blog-seo` skill의 참고 자료입니다. 검색량·경쟁도 수치는 도구마다 다르고 수시 변동하므로 **추정**으로 다루고 절대치에 의존하지 않습니다.

## 1. 키워드 소스

| 소스 | 얻는 것 |
|---|---|
| 네이버 검색광고 키워드도구 | 월간 검색량(PC/모바일)·경쟁 정도 추정 |
| 네이버 검색창 자동완성 | 실제 사용자가 많이 치는 조합 |
| 통합검색 하단 연관검색어 | 의미적으로 연결된 확장 키워드 |
| 지식iN·카페 질문 | 사용자의 진짜 고민(롱테일·질문형) |
| 상위노출 경쟁 글 | 경쟁이 노리는 키워드·소제목 구조 |

## 2. 검색 의도 분류

키워드를 의도별로 나눠 콘텐츠 형식을 맞춥니다.

- **정보형**: "○○ 방법", "○○ 효과" → 가이드·후기
- **거래형**: "○○ 가격", "○○ 추천", "○○ 구매" → 비교·구매 유도
- **지역형**: "강남 ○○", "○○ 근처" → 플레이스·지역 정보
- **내비게이션형**: 브랜드명 직접 검색 → 브랜드 콘텐츠

## 3. 키워드 군집 (핵심/세부/연관)

| 구분 | 정의 | 예시(필라테스 스튜디오) |
|---|---|---|
| 핵심(대표) | 검색량 크고 경쟁 치열 | 필라테스 |
| 세부(롱테일) | 검색량 작지만 의도 명확·경쟁 낮음 | 강남 필라테스 1:1 가격 |
| 연관 | 함께 검색·언급되는 주변어 | 체형교정, 거북목, 재활 |

> **신규·저품질 우려 블로그 전략(추정)**: 핵심 키워드 직공략보다 **세부(롱테일) 키워드**로 노출 경험을 쌓아 출처 신뢰도(C-Rank)를 축적한 뒤 점진적으로 핵심 키워드로 확장하는 편이 안전한 것으로 알려져 있습니다.

## 4. 배치 전략

- **제목**: 핵심 세부 키워드 1개를 자연스럽게 포함 (도배 금지).
- **도입부(첫 2~3문장)**: 핵심 키워드 + 검색자가 찾는 답의 예고(후킹).
- **소제목(H2/H3)**: 세부·연관 키워드를 분산 배치.
- **본문**: 연관 키워드를 맥락 속에 녹임. 같은 단어 기계적 반복 금지(저품질 위험).

## 5. 산출 양식 (키워드 군집표)

```
| 키워드 | 구분 | 검색의도 | 검색량(추정) | 배치 위치 |
|--------|------|----------|--------------|-----------|
| 강남 필라테스 1:1 | 세부 | 거래형 | 중 | 제목·도입부 |
| 필라테스 체형교정 | 연관 | 정보형 | 중 | H2 소제목 |
```
