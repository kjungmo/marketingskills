# 스마트스토어 리스팅 최적화 상세

> `naver-smartstore-seo` skill의 참고 자료입니다. 네이버 쇼핑 랭킹은 비공개 알고리즘으로 아래는 **추정·관행** 기반이며 정기 재검증이 필요합니다.

## 1. 상품명 작성 공식

```
[브랜드] [핵심키워드] [핵심속성/규격] [용도/대상]
```

- **좋은 예**: `오슬로 스테인리스 텀블러 500ml 보온보냉 휴대용`
- **나쁜 예**: `★최저가★ 정품 텀블러 텀블러 보온 보냉 예쁜 텀블러 강추` (반복·이벤트성·특수문자 → 어뷰징 위험)

원칙:
- 검색어와 일치하는 키워드를 자연스러운 어순으로.
- 동일 단어 반복·과장 수식어·불필요한 특수문자 금지.
- 핵심 속성(용량·색상·소재·수량)을 키워드로 포함.

## 2. 카테고리 매핑

- 상품에 **정확히 맞는** 카테고리를 선택합니다(잘못된 카테고리는 노출 손실, 적합도 하락).
- 경쟁 상위 상품이 어떤 카테고리에 등록됐는지 참고합니다.
- 표준 속성(브랜드·소재·사이즈 등)을 빠짐없이 입력합니다.

## 3. 태그 전략

- 상품명에 넣지 못한 **연관·세부 검색어**를 태그로 보완.
- 트렌드·시즌·용도·대상(선물/캠핑 등) 키워드 활용.
- 상품과 무관한 인기 태그(낚시) 금지.

## 4. 금지·주의 표현 (표시광고법)

- 절대적·최상급: "최저가", "1위", "유일", "100%" → 실증 자료 없으면 제거.
- 미입증 효능·효과 표현 주의.
- 타사 비방·부당 비교 금지.
- 상세는 `kr-ad-compliance` 로 점검.

## 5. 상세페이지 구성 템플릿

```
1. 상단 후킹 (3초 내 핵심 가치·구성·혜택)
2. 핵심 셀링포인트 3~5개 (이미지 + 짧은 카피)
3. 상세 스펙 (치수·소재·구성·사용법)
4. 실사용 이미지 / 비교 / 사용 시나리오
5. 자주 묻는 질문 (반품·A/S·배송)
6. 리뷰·신뢰 요소 (인증·후기)
7. 구매 유도 CTA
```

- 트래픽 대부분이 모바일이므로 모바일 가독성 우선.
- 상품정보제공고시 항목(소재·치수·제조국·A/S 등) 정확 표기(전자상거래법).

## 6. 리뷰·인기도 강화

- 배송 후 리뷰 요청, 포토리뷰 유도(대가성 리뷰는 정책·법 위반).
- 초기 판매·클릭·찜을 모으는 진입 오퍼 검토.
