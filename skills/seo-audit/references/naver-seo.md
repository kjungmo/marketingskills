# 네이버 SEO 이원 점검 (구글 + 네이버)

> 본 문서는 `seo-audit` skill의 한국 보정 참고 자료입니다. 네이버 검색 로직(C-Rank·D.I.A.+)은 **공식 미공개·수시 변동 알고리즘**이므로 아래 내용은 **추정 기반**이며 정기 재검증이 필요합니다. 단정적 수치는 피합니다.

## 구글 vs 네이버 차이 핵심

| 항목 | 구글 | 네이버 |
|---|---|---|
| 결과 구성 | 단일 웹 인덱스 중심 | 통합검색(블로그·VIEW·카페·지식iN·플레이스·쇼핑·뉴스 등 영역별) |
| 평가 축 | 페이지·도메인 권위(백링크 등) | 출처 신뢰도(C-Rank) + 문서 품질·검색의도 부합(D.I.A.+) |
| 구조화 데이터 | schema.org 리치결과 적극 활용 | schema.org 의존도 낮음(영역별 자체 노출 규칙) |
| 콘텐츠 자산 | 웹사이트/블로그 | 네이버 블로그·카페·플레이스가 노출에 유리 |

## 네이버 점검 항목

1. **노출 영역 매핑**: 타깃 키워드가 네이버에서 어느 영역(블로그/VIEW/플레이스/쇼핑/지식iN)에 노출되는지 확인하고, 해당 영역 자산을 확보합니다.
2. **네이버 서치어드바이저**: 사이트 등록·수집 요청·웹마스터 도구로 사이트가 네이버에 수집되는지 점검합니다.
3. **블로그 자산**: 주제 일관성(C-Rank), 원본성·체류시간(D.I.A.+) → `naver-blog-seo`.
4. **플레이스(로컬)**: 업체 정보·리뷰·사진 정비(로컬 검색 노출).
5. **쇼핑**: 상품 노출은 스마트스토어 최적화 → `naver-smartstore-seo`.
6. **모바일 우선**: 네이버 트래픽 대부분이 모바일입니다.

## 함께 보는 구글 점검

- 기존 `seo-audit` 의 기술·온페이지·콘텐츠 점검은 구글 기준 그대로 적용합니다.
- 네이버와 구글은 **별도 채널**이므로, 둘 다 타깃이면 자산·전략을 분리해 운영합니다.
