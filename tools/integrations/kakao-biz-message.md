# 카카오 비즈메시지 (알림톡 · 친구톡)

카카오톡으로 거래성(알림톡)·광고성(친구톡) 메시지를 발송. 한국에서 이메일보다 도달·열람률이 높은 핵심 채널.

> 발송은 보통 카카오 공식 인증 **발송 대행사**(예: NHN Cloud, SOLAPI, 알리고, 비즈엠 등)의 API를 통해 이루어집니다. 대행사별 스펙이 다르므로 선택한 대행사 문서를 확인합니다.

## Capabilities

| Integration | Available | Notes |
|-------------|-----------|-------|
| API | ✓ | 발송 대행사 API 경유 (알림톡/친구톡) |
| MCP | - | 네이티브 MCP 없음 |
| CLI | - | 대행사 API 스크립트 |
| SDK | ✓ | 대행사별 SDK(파이썬/Node 등) 제공 |

## Authentication

- **Type**: 대행사 API Key/Secret + **발신프로필키(senderKey)**
- **선행 조건**: 카카오톡 채널 개설 → 비즈니스 인증 → 발신프로필 등록
- **알림톡 템플릿 사전 등록·심사**: 변수(`#{변수}`)·버튼 포함 템플릿을 미리 등록하고 승인받아야 발송 가능

## Common Agent Operations

- **알림톡 발송**: 템플릿 코드 + 수신번호 + 변수 치환값 전달 (정보성)
- **친구톡 발송**: 채널 친구 대상 광고/콘텐츠 (이미지·버튼) — (광고) 표기 필요
- **대체발송(SMS/LMS)**: 알림톡 실패 시 문자 대체 발송 옵션
- **발송 결과 조회**: 성공/실패/수신 상태

## 규제 메모 (정보통신망법 — 현재 기준 확인 필요)

- **알림톡(정보성)**: 거래 사실 안내에 한정, 광고성 문구 혼입 금지.
- **친구톡(광고성)**: 사전 수신 동의(옵트인) + 시작부 **(광고)** + 야간(21~08시) 별도 동의 + **무료 수신거부** 안내.
- 카피 표현 점검은 `kr-ad-compliance`, 템플릿·전략은 `kakao-biz-message` skill 참고.
